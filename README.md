# Medical Billing AI 🏥

An agentic AI assistant for hospital operations — manage patients, billing, inventory, and reports using natural language, by typing or speaking, in English, Hindi, or Marathi.

## Features

- **Natural language chat** — ask for anything in plain English (or Hindi/Marathi, mixed or not): register a patient, generate a bill, check inventory, run custom reports.
- **Voice input & output** — speak your question using the mic button; the assistant can also read its replies back to you out loud, with a mute/unmute toggle.
- **Multi-agent architecture** — a context classifier routes each request to the right specialist (patient management, billing, inventory, sales, reports).
- **Structured response cards** — replies render as proper UI cards (patient details, dashboards, inventory lists, bills) instead of plain text.
- **PDF generation** — download real PDF documents on demand: patient reports, prescriptions, invoices, sales reports, and patient lists — all generated through one reusable Document Registry, so adding a new document type is a one-line change.
- **PDF comparison** — compare two time periods (e.g. this month vs. last month) or two doctors' patient loads, with automatic percentage-change calculations, through a generic Comparison Engine.
- **Document upload & Q&A** — upload one or more PDFs (not generated by this app) and ask questions about their contents, or ask the assistant to compare multiple uploaded documents against each other.
- **Fuzzy name matching** — corrects near-miss spellings of patient names (common with voice transcription) against what's actually in the database.

## Tech Stack

**Backend:** Python, Flask, SQLite, LangChain + Groq (LLM), Sarvam AI (speech-to-text & text-to-speech), ReportLab (PDF generation), pypdf (PDF text extraction).

**Frontend:** React, TypeScript, Vite, Tailwind CSS, Framer Motion.

## Setup

### Backend

```bash
cd Medical-Billing-Agent-V2
pip install flask flask-cors langchain-groq python-dotenv sarvamai groq reportlab pypdf
```

Create a `.env` file in this folder with:

```
GROQ_API_KEY=your_groq_key_here
SARVAM_API_KEY=your_sarvam_key_here
```

Run:

```bash
python app.py
```

### Frontend

```bash
cd project
npm install
npm run dev
```

Open the URL it prints (usually `http://localhost:5173`).

## Known Limitations

- PDF text extraction only works on PDFs with real selectable text — scanned/photographed documents need OCR, which isn't built in.
- The `patients` table doesn't store a registration date, so month-over-month "new patients" comparisons aren't possible without a schema change.
- Voice transcription and LLM model availability depend on Groq/Sarvam's current model lineup, which can change — check `console.groq.com/docs/deprecations` if you hit a `model_not_found` error.
